Import nhận chứng từ (offline)

Dùng khi hệ thống gặp sự cố, CTV nhập bằng Excel rồi upload lại để cập nhật nhận chứng từ.

Yêu cầu file
  • - Ngày nhận thực tế → lastest_received_date
  • - PGD → phát sinh PGD (ưu tiên PGD code, nếu trùng sẽ match full string)
  • - Ngày phát sinh → folder_created_date
  • - Folder type → folder_type_code
  • - Nhân sự → username (bắt buộc tồn tại)
  • - Mã thùng F88 → package_code (nếu chưa có sẽ tạo mới, user tạo = username trong file)
Nếu không tìm thấy quyển theo PGD + ngày phát sinh + loại quyển → fallback theo PGD + loại quyển (có cảnh báo).

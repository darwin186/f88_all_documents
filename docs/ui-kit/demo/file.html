File — ô chọn tệp gọn

Bọc một <input type="file"> trong .ui-file[data-ui-file]. Nút mũi tên mở hộp chọn tệp; có thể kéo thả tệp vào ô.

1. Mặc định

Hiện tên tệp + dung lượng; nút ✕ để bỏ tệp.

2. Giới hạn dung lượng + định dạng

data-max-mb="1", accept=".xlsx". Vượt giới hạn thì tự bỏ tệp và báo lỗi.

3. Nhiều tệp

Thuộc tính multiple: hiện "Đã chọn N tệp".

4. Cỡ nhỏ

data-size="sm"

5. Vô hiệu hóa

Thuộc tính disabled.

6. Thông báo lỗi tùy chỉnh

data-required-text khi bắt buộc mà chưa chọn (bấm Gửi để thử).
